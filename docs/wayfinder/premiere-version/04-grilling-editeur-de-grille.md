## Question

Quel est l'**éditeur de grille minimal** qui permet de concevoir une grille simple devant un public ?

18 fixe ce qu'est une grille, pas comment on la compose. `FEATURES.md` pose la question : comment un formateur compose-t-il nœuds, axes et regroupements sans que cela devienne un tableur ?

À trancher :

- ce qu'on **peut créer** : quels types de nœuds, combien de niveaux, un seul axe ou plusieurs ;
- les **fonctions et barèmes** exposés, parmi le catalogue F1 à F7 ;
- ce qui est **laissé de côté** : joker, dispenses, occurrences, exigences de remplissage, copie ;
- le **point de départ** : page blanche, gabarit, ou les deux ;
- le **retour immédiat** : erreurs de composition, aperçu du calcul sur un apprenant d'exemple ;
- si une **maquette** de l'éditeur est nécessaire avant d'en fixer le périmètre.
